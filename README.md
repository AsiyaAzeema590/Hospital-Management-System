A Hospital Management System (HMS) built using Spring Boot, implementing CRUD operations for managing Patients, Doctors, Appointments, and Billing. 
This project uses H2 Database for development and testing and Postman for API testing.

Features:

Patient management (Add, View, Update, Delete)

Doctor management (Add, View, Update, Delete)

Appointment booking and management

Billing system with CRUD operations

REST APIs built using Spring Boot

H2 in-memory database for easy testing

Tested with Postman

Tech Stack:

Backend: Spring Boot, Spring Data JPA

Database: H2 Database (in-memory)

Testing Tool: Postman

Language: Java
